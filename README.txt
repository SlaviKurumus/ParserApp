Парсер для поиска волонтеров на сайте добро.рф
Выполняет поиск по заданным критериям на сайте,
после чего переносит данные в бд на postgreSQL
Собирает следующие данные:
ФИО,
День рождения,
Ссылка на профиль,
ID,
Город,
Волонтерская организация,
Ссылки на социальные сети;
Для работы программы необходимы:
Python 3.10+,
dotenv,
selenium,
psycopg2;
Для настройки подключения и критерия поиска необходимо задавать параметры в .env
Все параметры которые имеют диапазон пишутся через - , например 1-99
Для выбора направлений нужно использовать следующие слова из списка:
(ЗОЖ, ЧС, Ветераны, Дети, Спорт, Животные, Старшее поколение, ОВЗ,
Экология, Культура, Поиск пропавших|Поиск, Урбанистика, Интеллектуальная помощь,
Права человека|Права, Образование, Другое, Коронавирус, Наука, Наставничество,СВО)
Регистр не важен, некоторые слова можно сокращать(Перчисленны сокращения через |),
Если слова дублируются, то фильтры по этому направлению выключатся, 
если написать слово неправильно, то критерий просто не задастся
